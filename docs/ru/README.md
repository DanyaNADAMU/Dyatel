# Документация Dyatel (Русский)

Этот каталог содержит системную документацию, руководства по эксплуатации и спецификации архитектуры **Dyatel** («Дятел») — высокопроизводительного многопротокольного игрового прокси и шлюза преодоления NAT.

## Навигация по документации

- **[Спецификация RFC-core](../RFC-core.md)**: Архитектурный контракт ядра Dyatel Core, цикл согласования состояний, транспорты (WireGuard, AmneziaWG, Xray) и REST API.
- **[Подключение своей машины](attach-your-machine.md)**: Пошаговая настройка проксера и клиента, пути через панель/CLI/Tier-0, контракт файрвола и диагностика.
- **[Обзор архитектуры](architecture/README.md)**: Топологические схемы сети и механика проброса трафика через CGNAT.
- **[Архитектурные решения (ADR)](adr/README.md)**: Реестр ключевых архитектурных решений проекта.
- **[Планы и развитие](plans/README.md)**: Дорожная карта и планируемые фазы разработки.
- **[English Documentation](../en/README.md)**: Документация на английском языке.
