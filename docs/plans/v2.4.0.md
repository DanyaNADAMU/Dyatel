## Known gaps

- Staging dial-in is unreachable from outside the park: `api.test.nada.mu`
  resolves to `2a13:d207:494:21::1`, which is inside berg's `/48` but bound to
  no interface, so the kernel forwards those packets instead of receiving
  them. Tunnels on `test` only handshake over `10.0.40.0/24`. Fixing it needs
  a real staging address (A record + berg DNAT for the tunnel port ranges),
  tracked in Infra.
- AWG on staging could not be validated end-to-end for the same reason; the
  milestone's AWG result stands on the park-internal runs from v2.3.4.
